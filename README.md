# 📹 CRUD de Videos — React + Supabase (desarrollo)

### Este proyecto es una pequeña aplicación creada con React que utiliza Supabase como backend para almacenar y gestionar una lista de videos.

## Funcionalidades (CRUD):

- Crear un nuevo video

- Leer/Listar los videos existentes

- Actualizar el estado del video (por ejemplo, si fue visto o no)

- Eliminar un video

## Tecnologías utilizadas

. ReactJS
- Supabase (Base de datos, API REST e integración con JS)
- Vite
- TailwindCSS
